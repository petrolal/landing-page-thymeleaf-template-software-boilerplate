Frequently Asked Questions

Everything you need to know about the template and tech stack.

What makes this template different from standard Spring Boot starters? ↓

Most Spring Boot setups require configuring frontend build tooling from scratch or linking complex SPA frameworks. This template combines HTMX and Tailwind CSS v4 in a single zero-Node Gradle build, pre-configured with JBang one-shot generation, SEO metadata, and full CI/CD deployment pipelines.

Do I need Node.js or npm installed to modify styles? ↓

No! Gradle automatically downloads the official standalone Tailwind CLI executable for your operating system. Running ./gradlew build or ./gradlew tailwindWatch compiles styles with zero JavaScript runtime dependencies.

How does the JBang generator work? ↓

Running jbang init@petrolal/landing-page-thymeleaf-template-first my-project triggers the included init.kt script. It downloads the template archive, refactors Kotlin packages recursively to your target package name, updates Gradle settings, and deletes generator artifacts so your new repository starts clean.

How is form spam prevented without CAPTCHA? ↓

The forms include an invisible honeypot field. Automated spam bots automatically fill every input field they encounter. The backend detects this and silently drops the submission without requiring human visitors to solve frustrating puzzles.

How do I enable the PostgreSQL database? ↓

PostgreSQL and Flyway dependencies are already in build.gradle.kts and application.yaml. Simply uncomment them and run docker compose up -d postgres to begin persisting leads and data.
