Open Source FAQ

Frequently Asked Questions

Everything you need to know about licensing, contributing, documentation, and sponsoring.

Is this template truly 100% free and open source? ↓

Yes! AuraLaunch is 100% free and open source distributed under the GNU General Public License v3.0 (GPL-3.0). You have the complete freedom to run, study, share, and modify the software.

How do I add or customize documentation pages? ↓

Simply add standard Markdown (.md) files into src/main/resources/docs/. The built-in documentation engine automatically parses YAML frontmatter, constructs the sidebar category tree, generates table of contents headings, and updates the Ctrl + K search index. Visit /docs for complete details.

How does Buy Me a Coffee support the project? ↓

All contributions via Buy Me a Coffee directly fund open-source development time, continuous dependency updates (Spring Boot, Kotlin, Tailwind), test server hosting, and community support. Supporters are acknowledged on GitHub and the project README!

Why is there no Node.js or npm required? ↓

We use the standalone Tailwind CSS v4 CLI binary. Gradle downloads the native binary for your architecture into .bin/ and executes it during builds. You get instant hot-reloading (./gradlew tailwindWatch) without managing package.json or bloated node_modules directories.

How can I contribute to the project? ↓

Contributions are warmly welcomed! You can open issues for bug reports or feature suggestions on GitHub, submit Pull Requests, or reach out via our contact form below for architecture discussions.
